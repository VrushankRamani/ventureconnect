# VentureConnect

VentureConnect is a Startup Investment Management Platform developed using PHP, MySQL, HTML, CSS, and JavaScript.

## Features
- Founder Dashboard
- Investor Dashboard
- Admin Panel
- Startup Management
- Investment Tracking
- Funding Analytics
- Responsive UI

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
